# ✈️ Autonomous Glider

An embedded-system/robotics project where I am developing an autonomous glider.

## 🛠️ Hardware Components
- ESP32 WROOM-32
- LiPo Battery
- MPU6050 IMU Sensor
- 4x SG90 Micro Servos

## 🖨️ 3D Printed Parts
For all 3D printable parts and assembly instructions, keep an eye on my Thingiverse page (https://www.thingiverse.com/Ili1000/designs).

## ⚠️ Project Status
This is a work in progress. Code, wiring, and design elements are unoptimized and subject to change!
